# Инструкция пользователя с привилегиями

Документ описывает работу с веб-интерфейсом DetectionStats для пользователя, которому выдан пароль доступа к закрытым разделам архива.

## Вход в веб-интерфейс

1. Откройте веб-интерфейс в браузере: `http://127.0.0.1:8080`.
2. Перейдите на вкладку **Архив срабатываний**.
3. Нажмите кнопку **Войти**.
4. Введите пароль архива.
5. Нажмите **Подтвердить**.

После успешной авторизации рядом с формой появится статус **Полный архив доступен**.

## Доступные разделы

Пользователь с привилегиями может работать со всеми основными разделами:

- **Последнее срабатывание** — публичная оперативная сводка по последнему событию, отображаемому на главной странице.
- **Архив срабатываний** — полный список событий, включая закрытые типы детекции.
- **Отчет по срабатыванию** — детальная карточка выбранного события с архивным кадром.

## Полный архив срабатываний

После входа в архиве доступны все типы событий, включая:

- пешеходов;
- маломобильных;
- детей;
- другие закрытые события, если они добавлены в конфигурацию.

В таблице архива отображаются:

- ID события;
- время события;
- камера;
- источник детекции;
- Redis-ключ;
- значение Redis-поля;
- отметка точности детекции.

Для открытия отчета нажмите на нужную строку таблицы.

## Фильтры архива

В архиве можно использовать следующие фильтры:

1. **Поля Redis** — выбор одного или нескольких полей, по которым нужно ограничить список событий.
2. **Детекция точна** — отображение событий, отмеченных как точные.
3. **Пешеходы на любой из камер > n** — отображение событий, где количество пешеходов хотя бы на одной камере больше указанного числа.

Фильтры применяются автоматически после изменения значения.

## Работа с отчетом по событию

В отчете по срабатыванию доступны:

- ID события;
- время события в часовом поясе UTC+3;
- значение сигнала;
- источник и камера-триггер;
- Redis-ключ и значение, вызвавшие срабатывание;
- счетчики людей, маломобильных и детей по камере-триггеру;
- архивный кадр события.

Для возврата в архив нажмите ссылку **← Назад к списку**.

## Проверка точности детекции

Для закрытых событий в отчете может отображаться флажок **Детекция точна**.

Чтобы отметить результат проверки:

1. Откройте отчет по нужному событию.
2. Сравните данные события с изображением камеры-триггера.
3. Установите или снимите флажок **Детекция точна**.
4. Дождитесь статуса **Сохранено**.

Если появляется статус **Ошибка сохранения**, проверьте, что авторизация не истекла, вернитесь в архив и выполните вход повторно.

## Выход из привилегированного режима

После завершения работы:

1. Перейдите на вкладку **Архив срабатываний**.
2. Нажмите **Выйти**.
3. Убедитесь, что статус изменился на приглашение войти для доступа к панели отладки.

Рекомендуется всегда выходить из привилегированного режима на общих или служебных рабочих местах.

## Рекомендации по безопасности

- Не передавайте пароль архива пользователям без допуска.
- Не сохраняйте пароль в общедоступных браузерах.
- Не оставляйте открытую авторизованную сессию без присмотра.
- При подозрении на компрометацию пароля сообщите ответственному администратору.
