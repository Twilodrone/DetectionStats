# Инструкция пользователя без привилегий

Документ описывает работу с веб-интерфейсом DetectionStats для пользователя без пароля доступа к закрытым разделам архива.

## Вход в систему

1. Откройте веб-интерфейс в браузере: `http://127.0.0.1:8080`.
2. Используйте вкладки в верхней части страницы:
   - **Последнее срабатывание** — главная страница с текущей статистикой и последним публичным срабатыванием.
   - **Архив срабатываний** — список доступных без авторизации событий.

## Главная страница «Последнее срабатывание»

На главной странице доступны:

- номер детектора;
- общее количество срабатываний;
- время последнего срабатывания;
- сведения о последнем публичном событии;
- кадр камеры, которая вызвала срабатывание;
- краткая сводка по камере-триггеру: источник, Redis-ключ, значение, количество людей, маломобильных и детей.

Данные обновляются автоматически. Если изображение или данные не меняются, обновите страницу браузера.

## Архив срабатываний без авторизации

Без привилегий в архиве отображаются только публичные события. По умолчанию это срабатывания по пешеходам, для которых доступ не требует пароля.

В архиве можно:

1. Просматривать последние доступные события в таблице.
2. Использовать фильтры:
   - выбор Redis-полей;
   - признак **Детекция точна**;
   - условие «Пешеходы на любой из камер > n».
3. Открывать отчет по событию кликом по строке таблицы.

## Отчет по срабатыванию

В отчете отображаются:

- ID срабатывания;
- время события в часовом поясе UTC+3;
- значение сигнала;
- камера и источник срабатывания;
- Redis-ключ и значение, которые привели к событию;
- архивный кадр камеры-триггера.

Если при открытии события появляется сообщение об ошибке доступа, значит событие относится к закрытому типу и доступно только пользователю с привилегиями.

## Ограничения пользователя без привилегий

Пользователь без привилегий не может:

- просматривать закрытые события, например события по маломобильным или детям;
- открывать отчеты и изображения закрытых событий;
- отмечать точность закрытой детекции;
- видеть полный архив отладочных срабатываний.

## Рекомендации при проблемах

- Если страница не открывается, проверьте адрес и доступность сервера приложения.
- Если не загружается кадр, подождите несколько секунд и обновите страницу.
- Если нужного события нет в списке, оно может относиться к закрытому типу или быть старше текущего лимита отображения.
- Для доступа к закрытым событиям обратитесь к ответственному сотруднику за паролем архива.
